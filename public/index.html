同じマイク音声を両方のリアルタイム API へ同時に送り、停止後に同じ録音をバッチ API へ送ります。 ElevenLabs はサーバー側の VAD で自動確定します。MAI はサーバー側の VAD がないため、ブラウザで同じ無音秒数を検出して commit を送ります。 「発話開始」「発話終了」はブラウザ側の音量判定なので目安です。 簡易 CER は記号を除き、算用数字を漢数字にそろえてから計算しています。結果と録音は results/runs/ に保存されます。
